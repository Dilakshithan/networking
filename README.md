Labs Summary
01. Multi-Subnet Routing (Static & RIP): Configured IPv4 addressing, static/default routes, and RIP dynamic routing across a 2-router, 3-subnet department topology.

02. VLAN & Inter-VLAN Routing: Segmented Layer 2 traffic into VLAN 10 and VLAN 20 across single/dual switches with 802.1Q trunking and Router-on-a-Stick sub-interfaces.

03. Multi-Area OSPF: Built a 5-router OSPF network (Areas 0, 1, and 2) with ABRs, DR/BDR elections, and inter-area (O IA) routing verification.

04. HTTP, HTTPS & TCP Analysis: Inspected TCP 3-way handshakes, sequence tracking, persistent HTTP/1.1, TLSv1.3, and HTTP/3 (QUIC/UDP) in Wireshark and PuTTY.

Tools Used
Cisco Packet Tracer, Cisco IOS CLI, Wireshark, PuTTY

How to Run
Open any .pkt file in Cisco Packet Tracer (v8.0+).

Check configurations and connectivity using show ip route, show ip ospf neighbor, ping, and tracert.
